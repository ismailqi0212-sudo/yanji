# 经营数据底稿
目标：将上传报告中重复出现的业务指标对齐成可继续使用的表，而不是复述财务摘要。
执行：调用 buildOperatingWorksheet 读取上传报告，提取业务收入、用户规模、ARPU、成本等；用户给了指标时优先指定 metrics。没有指标时先发现多期重复披露指标，注明覆盖范围，不声称抓取了全部业务数据。
口径：公司、业务定义、单位、币种、合并范围与期间必须一致。不能把期末人数与期间平均人数合并，不能把同名不同口径指标合并。跨期重述冲突保留待核对，不擅自选择。
计算：季度推导只由代码执行。累计流量可差分，存量、比例、ARPU和期间平均数不能直接差分；缺少必要累计期则留空。
交付：工具已生成表格，用户可以点指标画图、下载CSV并选入研报；不要在正文重抄整张表。只说明覆盖期间、关键口径和待补资料。数字引用原文sourceId。后续研究可检索或补读原文，但不能用外部财务接口替代用户要的业务披露。

回答保持简短：summary说明底稿范围，最多一段发现说明重要口径。表格是主要交付物，不展开成投资分析报告；禁止为改写focus在同一轮反复读取所有报告，补缺应检索或读取具体页。
